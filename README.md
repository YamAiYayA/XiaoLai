# 妍妍养成记

安卓育儿记录 App + 服务器 API。

## 手机两步走

1. 上传并安装 API（导入小程序数据）
   - 下载: `dist/baby-api-20260801.zip`
   - 宝塔解压到 `C:\wwwroot\api.guoziai.com\20260801`
   - 打开 https://api.guoziai.com/20260801/install.php 导入 `guozy`

2. 安装 App
   - 下载: `dist/XBB0.5.4.apk`
   - 用安装页生成的爸爸/妈妈 token 登录
   - 或邀请码 + 称呼

## APK 命名规则

每次更新产物命名为：`XBB` + 版本号，例如 `XBB0.5.4.apk`
